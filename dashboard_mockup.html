优化要点对比

左侧柱状图优化

✓
增加图表高度至 320px，给数据展示留足空间
✓
调整 grid 配置：top: 10px, bottom: 25px，消除多余留白
✓
增加右侧空间 right: 12%，确保数据标签完整显示
✓
坐标轴名称完整显示，不再被截断

右侧饼图优化

✗
移除饼图外侧的直接标签，避免与图形重叠
✓
增大饼图半径，居中显示，视觉更突出
✓
图例移至底部水平排列，带百分比显示
✓
悬停时通过 tooltip 显示详细数据

ECharts 配置代码（关键部分）

// 左侧柱状图配置 grid: { left: '3%', right: '12%', // 增加右侧空间 top: 10, // 减少顶部留白 bottom: 25, // 确保坐标轴名称显示 containLabel: true }, xAxis: { name: '考核销量(万)', nameLocation: 'end', nameGap: 10 } // 右侧饼图配置 series: [{ type: 'pie', radius: ['45%', 70], // 增大环形半径 center: ['50%', '45%'], // 居中偏上 label: { show: false }, // 关闭直接标签 emphasis: { label: { show: true, fontSize: 14 } } }], legend: { orient: 'horizontal', bottom: '5%', left: 'center', formatter: '{name} {c}%' }
